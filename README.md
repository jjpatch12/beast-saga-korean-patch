# Beast Saga 한국어 패치

Beast Saga 비공식 한국어 패치 배포 저장소입니다. 현재 배포 버전은 **v0.9.8**이며, 2026년 10월 15일 확인한 최신 Windows PC 게임 파일에 대응합니다. **2026년 10월 16일**까지 확정된 대사·명칭·판정 교정분을 반영했습니다.

[v0.9.8 다운로드](https://github.com/jjpatch12/beast-saga-korean-patch/releases/tag/v0.9.8) · [업데이트 내역](RELEASE_NOTES_v0.9.8.md)

## 2026-10-16 업데이트

- 인물 관계와 장면에 맞춰 검수·확정한 대사·선택지·서술의 말투와 일부 오역·명칭 불일치를 교정했습니다.
- 능력치·생활 기술 판정 표기 210곳과 설득 판정 3개 장면의 실패 조건 6곳을 수정했습니다. 실제 성공 요구치와 경험치 보상은 유지했습니다.
- 일부 아이템 표시명·설명과 인물 표시명을 정리했습니다. 내부 식별자와 능력치·효과량은 유지했습니다.
- v0.9.7 임시판의 최신 게임 호환 수정과 기존 누적 패치를 포함합니다. 이전 지원 원본·패치에서 업데이트할 수 있습니다.

이번 배포는 **확정된 검수분을 반영한 업데이트**이며, 전체 대사 전수검수 완료본은 아닙니다. 미확정 관계·명칭과 최종 검증 미완료 후보는 반영하지 않았습니다. 검증 범위는 [v0.9.8 릴리즈 노트](RELEASE_NOTES_v0.9.8.md)를 참고하세요.

위 목록은 이 배포본에 포함된 작업 범위입니다.

v0.9.6에서는 최신 게임 업데이트 호환, 동료 대화의 이름 조회, 아이템 정렬의 내부 키, PC용 낚시·곤충 채집 튜토리얼, 기존 세이브 인물 키 변환, 공격 무공 수치와 잔여 한자 표기를 수정했습니다. 아이템·장비·무공명 검수 결과, 미번역 분류명, 지도 임무 목표 표기와 능력치 글자 위치 수정도 포함합니다.

2026년 10월 2일 갱신에는 일부 대사 수정과 함께, 대사·선택지·주임무·보조임무·인물 임무의 아이템·무공명 불일치 및 관련 설명 수정을 반영했습니다. 지도 임무 목표에 표시되는 이름도 검수한 명칭에 맞췄습니다. 자세한 내용은 [릴리즈 노트](RELEASE_NOTES_v0.9.6.md)를 참고하세요.

2026년 10월 6일 갱신에는 한국어 상태 이름 때문에 중독·화상·출혈·점혈과 해당 중첩 효과가 전투에서 등록되지 않던 문제를 수정했습니다. 화면의 한국어 이름은 유지하고 내부 판정에는 원래 식별자를 사용합니다. 기타 상태 효과의 내부 키와 수치도 대조했으며, 이 상태 이상 수정은 기존 세이브를 직접 바꿀 필요 없이 적용됩니다.

v0.9.6 또는 v0.9.7 이용자도 v0.9.8 ZIP을 새로 다운로드하고 전체 압축을 푼 뒤 설치기를 실행해 주세요. 이전 버전의 릴리스는 보존합니다.

## 설치 방법

1. 게임을 완전히 종료합니다.
2. 릴리즈의 `Beast-Saga-Korean-Patch-v0.9.8.zip`을 다운로드해 **폴더에 압축을 모두 풉니다**.
3. 압축을 푼 폴더의 `한국어패치_설치.bat`을 실행합니다.
4. 게임 폴더를 자동으로 찾지 못하면 `BeastSaga.exe`가 있는 폴더 경로를 입력합니다. 다른 설치 위치를 지정하려면 명령 프롬프트에서 `"한국어패치_설치.bat" "D:\Games\Beast Saga"`처럼 실행할 수도 있습니다.
5. 설치 완료 메시지를 확인한 뒤 게임을 실행합니다.

BAT는 설치 실행용 파일입니다. 실제 데이터는 같은 위치의 숨김 폴더 `.korean_patch_data`에 있으므로, **BAT만 따로 옮기면 설치할 수 없습니다**.


지원되는 순정 게임과 기존 한국어 패치 설치본을 같은 ZIP으로 업데이트할 수 있습니다. 설치 전 원본은 게임 폴더의 `._KoreanPatch_Backup`에 백업합니다.

게임 설치본은 별도로 필요합니다. 배포 ZIP은 패치 설치기와 변경분 데이터를 포함합니다. 설치기에 포함된 Xdelta의 안내는 `.korean_patch_data/xdelta3_README.md`에서 확인할 수 있습니다.
