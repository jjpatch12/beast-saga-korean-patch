# Beast Saga 한국어 패치

Beast Saga 비공식 한국어 패치 배포 저장소입니다. 현재 배포 버전은 **v0.9.6**이며, 2026년 9월 29일 업데이트된 Windows PC 게임에 대응합니다.

[v0.9.6 다운로드](https://github.com/jjpatch12/beast-saga-korean-patch/releases/tag/v0.9.6) · [업데이트 내역](RELEASE_NOTES_v0.9.6.md)

## 패치 범위

| 영역 | 포함 내용 |
| --- | --- |
| 대사·선택지 | 기존 한국어 대사 및 선택지 번역, 인물 관계에 따른 말투 보정. |
| 메뉴·게임 정보 | 기존 메뉴와 인터페이스, 아이템·장비·무공 이름·설명 및 관련 UI 번역 |
| 임무·시스템 알림 | 배치 보정(크기 유지·아래쪽 이동), 대기 불가·이미 습득한 무공·일행 합류/이탈·경험치 등 확인된 중국어 알림 및 전투 문구 번역 |
| 인물명 | 대화 및 전투의 화자명·대상명과 표시 이름 보정. |
| 지도 | 지도 내 표기 한국어화와 글자 칸에 맞춘 배치 조정, 원본 이미지 크기 유지 |

위 목록은 이 배포본에 포함된 작업 범위입니다.

v0.9.6에서는 최신 게임 업데이트 호환, 동료 대화의 이름 조회, 아이템 정렬의 내부 키, PC용 낚시·곤충 채집 튜토리얼, 기존 세이브 인물 키 변환, 공격 무공 수치와 잔여 한자 표기를 수정했습니다. Alt 상호작용 강조 토글은 배포본에 포함하지 않습니다. 자세한 내용은 [릴리즈 노트](RELEASE_NOTES_v0.9.6.md)를 참고하세요.

## 설치 방법

1. 게임을 완전히 종료합니다.
2. 릴리즈의 `Beast-Saga-Korean-Patch-v0.9.6.zip`을 다운로드해 **폴더에 압축을 모두 풉니다**.
3. 압축을 푼 폴더의 `한국어패치_설치.bat`을 실행합니다.
4. 게임 폴더를 자동으로 찾지 못하면 `BeastSaga.exe`가 있는 폴더 경로를 입력합니다. 다른 설치 위치를 지정하려면 명령 프롬프트에서 `"한국어패치_설치.bat" "D:\Games\Beast Saga"`처럼 실행할 수도 있습니다.
5. 설치 완료 메시지를 확인한 뒤 게임을 실행합니다.

BAT는 설치 실행용 파일입니다. 실제 데이터는 같은 위치의 숨김 폴더 `.korean_patch_data`에 있으므로, **BAT만 따로 옮기면 설치할 수 없습니다**.


지원되는 순정 게임과 기존 한국어 패치 설치본을 같은 ZIP으로 업데이트할 수 있습니다. 설치 전 원본은 게임 폴더의 `._KoreanPatch_Backup`에 백업합니다.

게임 설치본은 별도로 필요합니다. 배포 ZIP은 패치 설치기와 변경분 데이터를 포함합니다. 설치기에 포함된 Xdelta의 안내는 `.korean_patch_data/xdelta3_README.md`에서 확인할 수 있습니다.
