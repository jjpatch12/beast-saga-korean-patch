# Beast Saga 한국어 패치

Beast Saga 비공식 한국어 패치 배포 저장소입니다. 현재 배포 버전은 **v0.9.6**이며, 2026년 9월 29일 업데이트된 Windows PC 게임에 대응합니다.

[v0.9.6 다운로드](https://github.com/jjpatch12/beast-saga-korean-patch/releases/tag/v0.9.6) · [업데이트 내역](RELEASE_NOTES_v0.9.6.md)

## 패치 범위

기존 한국어 번역과 2026년 9월 29일까지의 수정 사항을 통합했습니다.

| 영역 | 포함 내용 |
| --- | --- |
| 대사·선택지 | 기존 한국어 대사 및 선택지 번역, 인물 관계에 따른 말투 보정. 아화 대화의 `제게 맡기세요.`를 `나한테 맡겨.`로 수정한 내용 포함 |
| 메뉴·게임 정보 | 기존 메뉴와 인터페이스, 아이템·장비·무공 이름·설명 및 관련 UI 번역 |
| 장비 화면 | 장착·장착 해제 버튼 번역, `Z 길게: 분해` 문구 정리 및 위치를 왼쪽으로 24px 이동해 겹침·잘림 완화 |
| 장비·아이템 분류 | 장비 슬롯을 `머리·상의·하의·무기·장신구`, 방어구 재질을 `없음·천갑옷·철갑옷`으로 번역. 무공 계열과 아이템 하위 분류(`편지` 등)도 함께 정리 |
| 임무·시스템 알림 | 임무의 `개시` 번역과 배치 보정(크기 유지·아래쪽 이동), 대기 불가·이미 습득한 무공·일행 합류/이탈·경험치 등 확인된 중국어 알림 및 전투 문구 번역 |
| 인물명 | 대화 및 전투의 화자명·대상명과 복면인 1·2 등 표시 이름 보정. 일행 합류에 사용되는 28개 인물 번들의 표시 이름 한국어화(아수 등), 기존 색상 표시 유지 |
| 지도 | 미니맵 20개와 세계지도 1개의 리소스 반영. 지도 내 표기 한국어화와 글자 칸에 맞춘 배치 조정, 원본 이미지 크기 유지 |
| 이미지·글꼴 | 기존 오프닝 등 이미지 번역 및 한글 표시용 글꼴·UI 리소스 반영 |

위 목록은 이 배포본에 포함된 작업 범위입니다. 모든 분기와 화면을 실제 플레이로 검수했다는 의미는 아니며, 미번역·오탈자·화면 배치 문제는 추가 수정 대상입니다.

v0.9.6에서는 최신 게임 업데이트 호환, 동료 대화의 이름 조회, 아이템 정렬의 내부 키, PC용 낚시·곤충 채집 튜토리얼을 추가로 수정했습니다. 자세한 내용은 [릴리즈 노트](RELEASE_NOTES_v0.9.6.md)를 참고하세요.

## 설치 방법

1. 게임을 완전히 종료합니다.
2. 릴리즈의 `Beast-Saga-Korean-Patch-v0.9.6.zip`을 다운로드해 **폴더에 압축을 모두 풉니다**.
3. 압축을 푼 폴더의 `한국어패치_설치.bat`을 실행합니다.
4. 게임 폴더를 자동으로 찾지 못하면 `BeastSaga.exe`가 있는 폴더 경로를 입력합니다. 다른 설치 위치를 지정하려면 명령 프롬프트에서 `"한국어패치_설치.bat" "D:\Games\Beast Saga"`처럼 실행할 수도 있습니다.
5. 설치 완료 메시지를 확인한 뒤 게임을 실행합니다.

BAT는 설치 실행용 파일입니다. 실제 데이터는 같은 위치의 숨김 폴더 `.korean_patch_data`에 있으므로, **BAT만 따로 옮기면 설치할 수 없습니다**. 압축 해제 프로그램에 따라 숨김 폴더가 보일 수 있지만 삭제하지 마세요.

## 호환성·백업

Windows용 `BeastSaga.exe`와 `BeastSaga_Data`가 있는 설치본을 대상으로 합니다. 설치기는 444개 대상 파일의 SHA-256을 검사하며, 지원되는 순정 게임과 기존 한국어 패치 설치본을 같은 ZIP으로 업데이트합니다. 이미 최신 패치가 적용된 파일은 건너뜁니다. 알 수 없는 게임 업데이트나 다른 패치로 파일이 달라졌다면 강제로 덮어쓰지 않고 중단합니다.

설치 전 원본은 게임 폴더의 숨김 폴더 `._KoreanPatch_Backup`에 백업합니다. 이미 적용된 파일은 건너뛰고, 설치 도중 오류가 발생하면 이번 실행에서 변경한 파일을 자동 복원합니다. 복원 오류가 보고되면 표시된 백업 위치를 보관해 주세요.
