# Beast Saga 한국어 패치

Beast Saga 비공식 한국어 패치 배포 저장소입니다. 현재 배포 버전은 **v0.9.0**이며, 2026년 9월 24일 추가 수정분까지 같은 버전의 일반 릴리즈에 반영했습니다. GitHub의 사전 공개(Pre-release) 표시 없이 배포합니다.

[v0.9.0 다운로드](https://github.com/jjpatch12/beast-saga-korean-patch/releases/tag/v0.9.0)

## 패치 범위

2026년 9월 24일까지 적용한 한국어 번역과 수정 사항을 통합했습니다.

| 영역 | 포함 내용 |
| --- | --- |
| 대사·선택지 | 기존 한국어 대사 및 선택지 번역, 인물 관계에 따른 말투 보정. 아화 대화의 `제게 맡기세요.`를 `나한테 맡겨.`로 수정한 내용 포함 |
| 메뉴·게임 정보 | 기존 메뉴와 인터페이스, 아이템·장비·무공 이름·설명 및 관련 UI 번역 |
| 장비 화면 | 장착·장착 해제 버튼 번역, `Z 길게: 분해` 문구 정리 및 위치를 왼쪽으로 24px 이동해 겹침·잘림 완화 |
| 장비·아이템 분류 | 장비 슬롯을 `머리·상의·하의·무기·장신구`, 방어구 재질을 `없음·천갑옷·철갑옷`으로 번역. 무공 계열과 아이템 하위 분류(`편지` 등)도 함께 정리 |
| 임무·시스템 알림 | 임무의 `개시` 번역과 배치 보정(크기 유지·아래쪽 이동), 대기 불가·이미 습득한 무공·일행 합류/이탈·경험치 등 확인된 중국어 알림 및 전투 문구 번역 |
| 인물명 | 대화 및 전투의 화자명·대상명과 복면인 1·2 등 표시 이름 보정. 일행 합류에 사용되는 28개 인물 번들의 표시 이름 한국어화(아수 등), 기존 색상 표시 유지 |
| 지도 | 미니맵 20개와 세계지도 1개의 리소스 반영. 지도 내 표기 한국어화와 글자 칸에 맞춘 배치 조정, 원본 이미지 크기 유지 |
| 이미지·글꼴 | 기존 오프닝 등 이미지 번역 및 한글 표시용 글꼴·UI 리소스 반영 |

위 목록은 이 배포본에 포함된 작업 범위입니다. 모든 분기와 화면을 실제 플레이로 검수했다는 의미는 아니며, 미번역·오탈자·화면 배치 문제는 추가 수정 대상입니다.

## 설치 방법

1. 게임을 완전히 종료합니다.
2. 릴리즈의 `Beast-Saga-Korean-Patch-v0.9.0.zip`을 다운로드해 **폴더에 압축을 모두 풉니다**.
3. 압축을 푼 폴더의 `한국어패치_설치.bat`을 실행합니다.
4. 게임 폴더를 자동으로 찾지 못하면 `BeastSaga.exe`가 있는 폴더 경로를 입력합니다. 다른 설치 위치를 지정하려면 명령 프롬프트에서 `"한국어패치_설치.bat" "D:\Games\Beast Saga"`처럼 실행할 수도 있습니다.
5. 설치 완료 메시지를 확인한 뒤 게임을 실행합니다.

BAT는 설치 실행용 파일입니다. 실제 데이터는 같은 위치의 숨김 폴더 `.korean_patch_data`에 있으므로, **BAT만 따로 옮기면 설치할 수 없습니다**. 압축 해제 프로그램에 따라 숨김 폴더가 보일 수 있지만 삭제하지 마세요.

## 호환성·백업

Windows용 `BeastSaga.exe`와 `BeastSaga_Data`가 있는 설치본을 대상으로 합니다. 설치기는 309개 대상 파일의 SHA-256을 검사하며, 패치 제작에 사용한 원본, 앞서 배포한 v0.9.0 또는 이번 갱신본과 일치하는 파일만 허용합니다. 앞선 v0.9.0에서 내용이 다시 바뀐 133개 파일은 전용 업데이트 변경분을 포함하므로 같은 버전 위에 그대로 재설치할 수 있습니다. 게임 업데이트나 다른 패치로 파일이 달라졌다면 설치를 중단합니다. 지원 여부는 버전명 추정 대신 파일 검사로 판단합니다.

설치 전 원본은 게임 폴더의 숨김 폴더 `._KoreanPatch_Backup`에 백업합니다. 이미 적용된 파일은 건너뛰고, 설치 도중 오류가 발생하면 이번 실행에서 변경한 파일을 자동 복원합니다. 복원 오류가 보고되면 표시된 백업 위치를 보관해 주세요.

## 배포 파일·검증

- 배포 파일: `Beast-Saga-Korean-Patch-v0.9.0.zip` (원본 `Beast Saga 한국어 패치.zip`과 내용 동일)
- ZIP 크기: **1,107,669,125바이트**, 약 **1,056.4MiB**
- 적용 대상: **309개 파일**, Xdelta 방식의 변경분 패치
- 기존 v0.9.0 업데이트 호환: 내용이 달라진 **133개 파일**의 전용 변경분 포함
- 검증: 원본용 309개와 기존 v0.9.0용 133개 변경분의 복원 결과 해시 검사, 신규 설치·기존 패치 업데이트·오류 시 자동 복원 테스트, 현재 패치 적용 상태 인식 검사
- 업로드 ZIP의 설치기와 총 442개 변경분 데이터가 검증된 패키지와 일치하는지 SHA-256 확인

ZIP SHA-256:

```text
d9a8587aef9b86c93eb773c0c54361eb53c6a5444e658efc6e640c2366f72d73
```

게임 설치본은 별도로 필요합니다. 배포 ZIP은 패치 설치기와 변경분 데이터를 포함합니다. 설치기에 포함된 Xdelta의 안내는 `.korean_patch_data/xdelta3_README.md`에서 확인할 수 있습니다.
